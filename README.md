# Vampiric-game

2D survivors-like на Unity (в духе Vampire Survivors): волны врагов, оружие с эволюциями, карты прокачки, артефакты и хаб между забегами.

## Стек

- Unity `6000.0.79f1`, 2D URP, Input System
- Гибридный рантайм: **ECS + Burst** для врагов, снарядов, пикапов и попаданий; **GameObject** для игрока, UI и хаба
- Entities `1.4.8` (без Entities Graphics и DOTS Physics)

## Что есть в игре

- Хаб и забег (`Hub` → `SampleScene`)
- Волны врагов, пикапы опыта/золота/магнита/сердец
- Оружие с эволюциями (веер, залп, миниган, самонаведение, рикошет, граната)
- Карты при левелапе
- Артефакты: экип, рюкзак, фьюжн в хабе, сейв профиля

## Как открыть

1. Поставь Unity `6000.0.79f1`.
2. Открой папку репозитория как проект.
3. Запускай Play **со сцены Hub**, не с `SampleScene`.

Подробный технический статус — в `HANDOFF.md`.
